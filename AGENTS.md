# Repository instructions

## Commit attribution

- When creating or amending a commit, do not add an AI agent, coding assistant, model, or automation identity as a `Co-authored-by:` trailer.
- It is acceptable to use the user's configured Git author and committer identity.
- Preserve human co-authors when the user explicitly requests them.
- Before committing, inspect the final commit message and remove any agent co-author trailer.
- Do not rewrite existing history or change Git identity settings solely to enforce this policy.
