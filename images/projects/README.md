# DVD Project Lab artwork

`dvd-video.svg` is the clean white, transparent 5:3 vector supplied in the DVD
Project Lab kit. Its path geometry is unchanged. The kit removed the original
embedded stylesheet and style attribute, used presentation attributes, and set
the silhouette to white. The deployed SVG contains only the SVG container and a
path: no scripts, event handlers, embedded styles, external resources, or background.

The site loads this local file as an alpha mask for the decorative DVD animation.
Movement and brief colored offsets are implemented separately in the Projects
site; the asset itself has no animation or network behavior.
